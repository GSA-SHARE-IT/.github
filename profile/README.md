# GSA SHARE IT

Resources to help federal agencies implement the SHARE IT Act and support software sharing and reuse across government.

## About

GSA-SHARE-IT is a GSA owned GitHub organization that brings together SHARE IT Act guidance, tools, metadata standards, and examples.

These repositories were developed through collaboration between The GSA SHARE IT Act WG, and the Centers for Medicare & Medicaid Services (CMS) Open Source Program Office, to help agencies document their software, maintain software inventories, and support discovery and reuse across government.

## Vision

A Federal Government Ecosystem where agencies can discover, share, and reuse software to reduce duplicative work and better serve the public.

## Mission

Provide clear guidance and practical, reusable tools that help federal agencies implement SHARE IT Act requirements.

## Get Started

Start with the [SHARE IT Act landing page repository](https://github.com/GSA-SHARE-IT/site) for guidance and links to available resources.

Explore the repositories below based on what you need to do:

| Resource | Purpose |
| --- | --- |
| [codejson-schemas](https://github.com/GSA-SHARE-IT/codejson-schemas) | Explore the `code.json` metadata standard for federal software projects. |
| [codejson-form](https://github.com/GSA-SHARE-IT/codejson-form) | Generate a `code.json` file using a form. |
| [codejson-action](https://github.com/GSA-SHARE-IT/codejson-action) | Automate `code.json` creation and maintenance with a GitHub Action. |
| [codejson-index](https://github.com/GSA-SHARE-IT/codejson-index) | Compile an index of agency `code.json` files. |
| [demo-repo](https://github.com/GSA-SHARE-IT/demo-repo) | Explore an example demonstrating SHARE IT Act tooling. |
| [govcode-index](https://github.com/GSA-SHARE-IT/govcode-index) | Access the dataset for the Federal Software Inventory. |
| [GSA-index.json](https://github.com/GSA-SHARE-IT/GSA-index.json) | View GSA’s SHARE IT repository index. |

To report a problem, suggest an improvement, or propose a change, use the relevant repository’s issues or pull requests. Review its README and contribution guidance before getting started.
